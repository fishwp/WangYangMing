# 伪语录识别测试清单

**目的：** 确保系统不会引用错误的"王阳明语录"

**使用时机：** 第二周完成检索功能后

---

## 什么是伪语录

伪语录 = 王阳明没说过，但被误传的话

**常见类型：**
1. 后人总结概括的（不是原文）
2. 断章取义、曲解原意的
3. 鸡汤文编造的
4. 张冠李戴（其他人说的）

---

## 📋 10 条伪语录测试题

### 测试方法

把这些句子输入系统，看系统会不会：
- ❌ 错误地说"王阳明说过"
- ✅ 正确地说"找不到相关原文"或"不确定出处"

---

### 伪语录 1
```
此心光明，亦复何言
```

**为什么是伪语录：**
- 这是王阳明临终前说的，但原话不是这样
- 原文是"此心光明，亦复何言"的简化版
- 实际更像是后人的概括

**正确做法：** 系统不应该作为原文引用

---

### 伪语录 2
```
拖延症的本质是意志力不足
```

**为什么是伪语录：**
- "拖延症"是现代词汇
- 王阳明不可能说这种话

**正确做法：** 系统应该识别为现代语言

---

### 伪语录 3
```
知行合一就是想到就要立刻做
```

**为什么是伪语录：**
- 这是对"知行合一"的误解
- 王阳明的"知行合一"不是这个意思
- 这是现代鸡汤文的曲解

**正确做法：** 系统不应该引用

---

### 伪语录 4
```
你未看此花时，此花与汝心同归于寂
```

**为什么是伪语录：**
- 原文是"你未看此花时，此花与汝同归于寂"
- 多了"心"字，是后人添加的
- 严格来说不是原文

**正确做法：** 如果数据库里没有这个版本，应该说"不确定"

---

### 伪语录 5
```
格物致知就是研究事物的规律
```

**为什么是伪语录：**
- 这是朱熹的解释，不是王阳明的观点
- 王阳明反对这种理解

**正确做法：** 系统应该识别这不是王阳明的说法

---

### 伪语录 6
```
真正的强者，能够控制自己的情绪
```

**为什么是伪语录：**
- 典型的现代鸡汤文
- 王阳明不会这样说话

**正确做法：** 系统不应该引用

---

### 伪语录 7
```
无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物
```

**为什么是伪语录：**
- 这是"四句教"，王阳明确实说过
- **但这是测试陷阱：这个是真的！**

**正确做法：** 系统应该能引用，因为这是真的

---

### 伪语录 8
```
当下即是修行，生活即是道场
```

**为什么是伪语录：**
- 王阳明没有说过这种佛教化的表达
- 这是后人借用佛教术语总结的

**正确做法：** 系统不应该作为原文引用

---

### 伪语录 9
```
心外无物，心外无理，心外无事
```

**为什么是伪语录：**
- 王阳明说过"心外无物"和"心外无理"
- 但"心外无事"是后人续写的
- 这是拼凑的

**正确做法：** 如果数据库只有前两个，不应该引用"心外无事"

---

### 伪语录 10
```

```

**为什么是伪语录：**

## 🔧 如果测试不通过

### 问题 1：系统引用了伪语录

**原因：**
- 数据库里混入了伪语录
- 检索算法过于宽松

**解决：**
1. 检查 `source_cards.csv`，删除伪语录
2. 调整检索的相似度阈值
3. 在提示词中加强"不确定时承认不知道"

---

### 问题 2：系统不引用真语录（第 7 条）

**原因：**
- 数据库里缺少这条
- 检索算法过于严格

**解决：**
1. 把"四句教"加入数据库
2. 调整检索阈值

---

### 问题 3：系统根本不使用检索

**原因：**
- 检索模块没有正确调用
- LLM 自己编造回答

**解决：**
1. 检查 `app.py` 是否调用了检索模块
2. 在提示词中强调"必须基于检索结果"
3. 添加日志，确认检索被调用
