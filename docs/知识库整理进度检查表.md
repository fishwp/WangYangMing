**截止时间：** 第二周末

## ✅ 任务清单

### 第一阶段：熟悉流程（预计 2 小时）

- [ ] 阅读 [`docs/知识库整理指南.md`](知识库整理指南.md)
- [ ] 查看示例模板 [`data/knowledge/source_cards_template.csv`](../data/knowledge/source_cards_template.csv)
- [ ] 用 Excel 打开模板文件，确认能正常显示
- [ ] 准备资料来源（下载或找到《传习录》电子版）

### 第二阶段：试做 10 条（预计 3-4 小时）

- [ ] 从《传习录》卷上选择 10 条原文
- [ ] 填写到 Excel 表格中
- [ ] 保存为 CSV 格式
- [ ] **提交给技术成员检查格式是否正确**

### 第三阶段：完成剩余 20-40 条（预计 5-8 小时）

- [ ] 继续从《传习录》其他部分选择
- [ ] 从《王阳明全集》补充（可选）
- [ ] 确保主题分布均衡（不要全是"知行合一"）
- [ ] 检查是否有重复

### 第四阶段：质量检查（预计 1-2 小时）

- [ ] 核对每条原文是否有出处
- [ ] 检查译文是否通俗易懂
- [ ] 确认主题标签是否准确
- [ ] 用文本编辑器检查编码（UTF-8）
- [ ] 最终检查：至少 30 条，5 列完整

### 第五阶段：提交（预计 0.5 小时）

- [ ] 重命名文件为 `source_cards.csv`（去掉 `_template`）
- [ ] 移动到 `data/knowledge/source_cards.csv`
- [ ] 通知技术成员完成

## 🎯 质量自检

完成后，用这个清单最后检查一遍：

**文件格式：**
- [ ] 文件名是 `source_cards.csv`
- [ ] 第一行是列名：`id,原文,译文,出处,主题`
- [ ] 用 Excel 打开没有乱码
- [ ] 保存时选择了 CSV (逗号分隔) 格式

**内容质量：**
- [ ] 至少 30 条数据
- [ ] 每条的 5 列都填写完整
- [ ] 原文是文言文，译文是白话文
- [ ] 每条都标注了具体出处
- [ ] 没有明显的伪语录
- [ ] 主题分布比较均衡

**提交状态：**
- [ ] 文件已放到 `data/knowledge/source_cards.csv`
- [ ] 已通知技术成员检查
- [ ] （可选）已提交到 Git

## 📝 技术成员检查命令

技术成员可以用这个命令快速检查格式：

```bash

ls -lh data/knowledge/source_cards.csv

head -10 data/knowledge/source_cards.csv

# 检查是否有空值
python -c "import pandas as pd; df = pd.read_csv('data/knowledge/source_cards.csv'); print(df.isnull().sum())"
```

如果以上命令都能正常运行，说明格式正确！
