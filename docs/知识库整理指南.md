# 知识库整理指南

**目标：** 整理 30-50 条王阳明原典语录，制作成资料卡，供系统检索使用。

**负责人：** 成员 C（知识库整理组）

**截止时间：** 第二周末

---

## 📋 你需要交付什么

一个 CSV 文件：`data/knowledge/source_cards.csv`

包含 30-50 条王阳明原文，每条记录包含：
- 原文（王阳明的原话）
- 白话翻译
- 出处（哪本书、第几卷）
- 主题标签（这句话讲什么）

---

## 📝 CSV 文件是什么

CSV = Comma-Separated Values（逗号分隔值）

**就是用逗号分隔的表格文件**，可以用 Excel 或 WPS 打开。

**示例：**

```csv
id,原文,译文,出处,主题
1,"知是行之始,行是知之成","知是行动的开始,行动是知的完成","《传习录》卷上","知行合一"
2,"心即理也","心就是天理","《传习录》卷上","心学核心"
```

**在 Excel 中看起来像这样：**

| id | 原文 | 译文 | 出处 | 主题 |
|----|------|------|------|------|
| 1 | 知是行之始,行是知之成 | 知是行动的开始,行动是知的完成 | 《传习录》卷上 | 知行合一 |
| 2 | 心即理也 | 心就是天理 | 《传习录》卷上 | 心学核心 |

## 🛠️ 工作步骤（两种方式任选）

### 方式一：用 Excel/WPS（推荐，更简单）

#### 第 1 步：创建表格

1. 打开 Excel 或 WPS 表格
2. 在第一行输入列名（表头）：
   - A1: `id`
   - B1: `原文`
   - C1: `译文`
   - D1: `出处`
   - E1: `主题`

#### 第 2 步：填写数据

从第 2 行开始，每一行填一条语录。

**示例：**

| A (id) | B (原文) | C (译文) | D (出处) | E (主题) |
|--------|----------|----------|----------|----------|
| 1 | 知是行之始,行是知之成 | 知是行动的开始,行动是知的完成 | 《传习录》卷上 | 知行合一 |
| 2 | 心即理也 | 心就是天理 | 《传习录》卷上 | 心学核心 |
| 3 | 破山中贼易,破心中贼难 | 打败外在的敌人容易,战胜内心的欲望很难 | 《传习录》卷下 | 克己功夫 |

#### 第 3 步：保存为 CSV

1. 点击 **文件 → 另存为**
2. **文件名**：`source_cards.csv`
3. **保存位置**：桌面（先保存到桌面，后面再移动）
4. **文件类型**：选择 **CSV (逗号分隔) (*.csv)**
5. 点击保存

**⚠️ 常见问题：**
- 如果 Excel 提示"某些功能可能丢失"，点击"是"继续
- 如果打开 CSV 文件看到乱码，选择编码为 **UTF-8**

## 📚 从哪里找原文

### 推荐来源

1. **《传习录》**（最重要）
   - 王阳明心学的核心著作
   - 建议先从这里选 20-30 条
   - 在线阅读：[国学网](http://www.guoxue.com/)

2. **《王阳明全集》**
   - 包含书信、诗文、奏疏
   - 可以补充 10-20 条

3. **二手整理**
   - 豆瓣、知乎上的"王阳明语录"整理
   - ⚠️ 注意：必须核对原文，避免伪语录

### 如何核对是否伪语录

❌ **这些是伪语录（王阳明没说过）：**
- "此心光明，亦复何言" ← 这是别人概括的，不是原文
- "拖延症是意志力不足" ← 现代词汇，王阳明不可能说

✅ **如何核对：**
1. 搜索原文 + "传习录" 或 "王阳明"
2. 看是否能找到完整的出处标注
3. 如果只在鸡汤文里出现，大概率是伪语录

## 📊 每列填什么

### 第 1 列：id（序号）

**要求：** 从 1 开始的连续数字

**示例：**
```
1
2
3
...
50
```

---

### 第 2 列：原文

**要求：** 王阳明的原话（文言文）

**注意事项：**
- 保留古文标点（逗号、句号）
- 不要添加现代解释
- 长度建议：10-100 字

**示例：**
```
知是行之始,行是知之成
心即理也
破山中贼易,破心中贼难
```

---

### 第 3 列：译文

**要求：** 白话文翻译，让现代人能看懂

**注意事项：**
- 用日常口语，不要文绉绉
- 避免过度解读
- 长度建议：15-150 字

**示例：**
```
知是行动的开始,行动是知的完成
心就是天理
打败外在的敌人容易,战胜内心的欲望很难
```

**翻译技巧：**
- "知行合一" → "知和行是一体的"
- "致良知" → "实现内心的良知"
- "心即理" → "心就是天理"

---

### 第 4 列：出处

**要求：** 标明这句话来自哪里

**格式：** `《书名》卷次/篇名`

**示例：**
```
《传习录》卷上
《传习录》卷下·答顾东桥书
《王阳明全集》卷二十一·书信
```

**如果不确定具体卷数：**
```
《传习录》
《王阳明全集》
```

---

### 第 5 列：主题

**要求：** 用 2-4 个字概括这句话讲什么

**推荐主题词：**
- 知行合一
- 心学核心
- 克己功夫
- 立志
- 致良知
- 格物致知
- 省察
- 事上磨练
- 不动于物
- 诚意正心

**示例：**
```
知行合一
心学核心
克己功夫
立志
```

**可以一句话对应多个主题吗？**
- 可以，用分号隔开：`知行合一;致良知`
- 但建议只选最核心的 1-2 个

## ✅ 质量标准

### 数量要求
- ✅ 至少 30 条
- 🌟 推荐 40-50 条
- ❌ 不超过 100 条（太多影响检索精度）

### 内容要求
1. **必须是王阳明本人说的**（不是别人概括）
2. **必须标注出处**（哪本书、第几卷）
3. **译文通俗易懂**（不要文言文翻译文言文）
4. **主题明确**（便于后续检索）

### 避免的问题
❌ 伪语录（王阳明没说过）
❌ 后人总结的概括（不是原文）
❌ 出处不明的网络语录
❌ 译文过于学术化（要口语化）

## 💡 常见问题

### Q1: 我打开 CSV 文件是乱码怎么办？

**A:** 编码问题，操作如下：

1. 用记事本/文本编辑器打开 CSV
2. 点击 **文件 → 另存为**
3. 编码选择 **UTF-8**
4. 保存

### Q2: 我不确定某句话是不是王阳明说的？

**A:** 三个办法：

1. 搜索"这句话 + 传习录"，看能否找到原文
2. 在[国学网](http://www.guoxue.com/)搜索关键词
3. 问技术成员或项目负责人

**原则：不确定就不要加！**

### Q3: 主题词不知道怎么选？

**A:** 参考这个分类：

| 原文关键词 | 推荐主题 |
|-----------|---------|
| 知行、知是行、行是知 | 知行合一 |
| 心即理、心外无物 | 心学核心 |
| 良知、致良知 | 致良知 |
| 立志、志 | 立志 |
| 省察、自省 | 省察 |
| 克己、去私欲 | 克己功夫 |
| 事上磨、事上练 | 事上磨练 |

### Q4: 译文要翻译得多白话？

**A:** 标准：**高中生能看懂。**

❌ 太文言：知为行之端绪，行为知之归宿
✅ 刚刚好：知是行动的开始，行动是知的完成
❌ 太口语：想做的事就赶紧做呗

### Q5: 30 条要多久能整理完？

**A:** 时间估算：

- 新手：5-8 小时（1-2 天）
- 熟悉心学的人：3-5 小时（1 天）

**建议：**
- 第 1 天：整理 15 条，熟悉流程
- 第 2 天：完成剩余 15-20 条
- 第 3 天：检查、修订、补充
